For the dev team

Every page above composes only from primitives shipped in @z-protocol/ui. No bespoke CSS per page — surfaces, plates, badges, and tables are reused so the look stays consistent. Hash truncation, copy-on-click, address tooltips, theme toggle, and the search "/" shortcut are all wired in the components. The only per-page work is composition: arrange primitives, plug data in, ship.
