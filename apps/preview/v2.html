02 · Surface system

Field, Plate, Glass, Aurora, Photographic

Every screen, slide, and card in v2 is built by stacking from these five surfaces. Layering rules: plates can sit on field, aurora, or photo. Glass can sit on any. Aurora never on aurora; photo never on photo.

FIELD The cream or mist ground itself. Carries the page. No radius, no border by default.
PLATE Soft white card on field. Radius 20–28px, 1px ink-08 border, plate shadow. The default building block.
GLASS Translucent surface with backdrop blur. For nav, eyebrow pills, ghost buttons, and floating modules over photography.
AURORA · WARM Diffuse warm radial gradient as atmospheric weather behind hero copy or empty states.
AURORA · COOL Cool variant for night/think contexts and second-page heroes.
PHOTOGRAPHIC Full-bleed wide or close-up. Type rides over negative space; UI rides on glass plates above.

09 · Acceptance test

Eight checks before any v2 piece ships

From brand-direction-v2.md §15. Designers run this list before submitting any artefact for review. Pin to the Figma cover frame.

  • ✓ One ground (field, aurora, photographic) is dominant. Layered surfaces are clearly subordinated.
  • ✓ Accent discipline holds — one CTA color used once, one UI accent used sparingly, no color zoo.
  • ✓ Display type lands at one of the four scale steps. No free-form sizing.
  • ✓ At least 30% of the frame is negative space.
  • ✓ One clear focal idea — if you have to explain what the asset is about, kill it.
  • ✓ Motion (if any) settles, doesn't snap.
  • ✓ A prefers-reduced-motion user gets the same legible page.
  • ✓ The asset feels correct on a 27-inch matte monitor and a printed cream card.
